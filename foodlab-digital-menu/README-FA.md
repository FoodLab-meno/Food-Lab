# منوی دیجیتال FoodLab

نسخه شروع منوی دیجیتال راست‌چین و مناسب موبایل، با پنل مدیریت قیمت‌ها.

## فایل‌ها
- `index.html`: منوی عمومی مشتریان
- `admin.html`: صفحه ورود مدیر و تغییر قیمت‌ها
- `style.css`: طراحی سبز و نارنجی
- `menu.js` و `admin.js`: منطق نمایش منو و مدیریت قیمت
- `config.js`: اطلاعات اتصال Supabase
- `supabase-setup.sql`: ساخت جدول و محصولات اولیه

## راه‌اندازی دیتابیس و پنل مدیریت
1. در Supabase یک پروژه بسازید.
2. محتوای `supabase-setup.sql` را در SQL Editor اجرا کنید.
3. در Authentication > Users یک کاربر مدیر با ایمیل و رمز قوی ایجاد کنید.
4. ثبت‌نام عمومی کاربران را غیرفعال کنید و فقط حساب مدیر مورداعتماد را نگه دارید.
5. از Project Settings > API، آدرس پروژه و کلید عمومی `anon` یا `publishable` را بردارید.
6. این دو مقدار را در `config.js` جایگزین مقادیر نمونه کنید.
7. فایل‌ها را در یک مخزن GitHub آپلود کنید. از Settings > Pages انتشار را از شاخه `main` و پوشه `/root` فعال کنید.

## امنیت
- هرگز کلید `service_role` را در فایل‌های سایت یا GitHub قرار ندهید.
- فقط کلید عمومی `anon`/`publishable` مجاز است.
- سیاست‌های RLS فعال هستند؛ برای نسخه نهایی بهتر است سیاست ویرایش به شناسه دقیق حساب مدیر محدود شود.

## توجه
قیمت‌ها عمداً خالی هستند تا بعد از بازبینی فهرست و قیمت‌های منوی چاپی وارد شوند. نام محصولات نیز پیش از انتشار نهایی باید با شما تطبیق داده شوند.
